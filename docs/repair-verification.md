## 未通过与未验证

- **DSH 内 Shell 执行未通过**：Windows 沙箱启动返回 Win32 5，经一次批准后的重试返回 `spawn EPERM`。真实文件读取和补丁通过；主代理另行运行文件测试仅证明文件结果，不替代 DSH Shell 验收。
- 工作区选择依赖宿主原生目录窗口，浏览器测试预置了隔离工作区登记。Go 凭据和模型配置仍完全通过界面操作。
- 浏览器验收未覆盖真实 OAuth 提供方的交互式授权、真实账户过期和配额耗尽；这些失败分支使用受控测试。
- 非 Go 提供方隔离、HTTP 200 后流错误、包装卸载和运行时所有者竞争有受控测试；未将其称为真实供应商或宿主热卸载 E2E。浏览器证明的是卸载后重启恢复。
- 未执行旧版本混装的真实验收；两个候选包应配对测试。外部客户端三协议的真实 Go 网关请求未执行，网关协议证据来自受控 HTTP 测试。
- 窄屏是桌面浏览器视口测试，不代表手机软键盘或 Remote Kit 手机端验收。
